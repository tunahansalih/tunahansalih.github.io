# Deterministic general-coding queue

Use this queue only for the curriculum task that names the same row. Do not browse for a different problem.

## Rules

1. Turn AI assistance and coding autocomplete off.
2. Read the prompt once. Before coding, say the likely pattern and target complexity aloud.
3. Start the task timer shown in the curriculum. Stop when it expires, even if unfinished.
4. Run the examples plus at least two edge cases of your own.
5. Log: result, elapsed time, first broken step, and one recognition cue.
6. If you solved the primary problem within the previous 60 days, use its fixed alternate. Otherwise always use the primary.
7. Never do both the primary and alternate in one session.
8. Do not open future problem links. In particular, keep W2-A and W2-B unopened until the G1 timer starts.

## What “done” means

- **Pass:** correct within the time cap, complexity stated before coding, and edge cases pass.
- **Implementation miss:** the plan was right but code or tests failed.
- **Retrieval miss:** no viable pattern was identified in five minutes.
- **Time-management miss:** a viable solution existed but was not completed by the cap.
- **Communication miss:** silence exceeded 20 seconds or the approach was not narrated.

The queue intentionally omits Weeks 8 and 12 (slack weeks) and Week 15 (onsite stamina/launch).
